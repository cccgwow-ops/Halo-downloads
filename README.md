# Halo · 桌面浮签

Halo 把你选中的 Chrome 网页收进桌面球。把鼠标移到球上即可展开浮签，点图标可以回到原来的标签页。使用时需要安装 Chrome 扩展和本机桌面组件。

## 下载与安装

桌面组件 1.8.2 适用于搭载 Apple 芯片的 Mac，系统要求为 macOS 13 或更高版本。[下载 Mac 桌面组件（Apple 芯片）](https://github.com/cccgwow-ops/Halo-downloads/releases/download/v1.8.2/Halo-macOS-Store-1.8.2-arm64.zip)

1. 解压下载的 ZIP，在解压得到的文件夹里双击 `install.command`。安装仅作用于当前 Mac 用户。此版本使用本地 ad hoc 签名，尚未经过 Apple 公证。
2. 在 Google Chrome 安装「Halo · 桌面浮签」扩展。商店链接将在扩展通过审核并公开发布后生效。[Chrome 网上应用店](https://chromewebstore.google.com/detail/mecnpfainjbeehgmljgglpcnppbaodji)
3. 打开一个普通网页，点 Chrome 工具栏中的 Halo。面板显示「桌面已连接」后，点「将当前标签收进 Halo」，即可在桌面球里找到该页。

右键点击桌面球可退出桌面组件，已保存的浮签会保留。下次点 Chrome 工具栏里的 Halo 即可重新启动。卸载桌面组件时，从同一安装包运行 `uninstall.command`。Chrome 扩展可在浏览器的扩展管理页面移除。
